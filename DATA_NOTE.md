# Data Note

CampusPulse uses a fictional, synthetic campus dataset created specifically for interaction prototyping.

The 18 study spaces, ratings, task-fit scores, coordinates and community signals do not describe a real university.

The map is schematic and must not be used for navigation.

All values are generated from four design archetypes (Deep Focus, Quick Work, Social Study, Group Collaboration) plus a deterministic random seed (`42`). They are **not** observed campus measurements.

The optional Demo pulse on a space detail page is stored only in the current browser session. It is a community-layer concept, not live campus activity.

Purpose: educational and portfolio prototyping only.

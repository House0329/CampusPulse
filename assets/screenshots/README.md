# Screenshot instructions

Capture these four product surfaces after running `streamlit run app.py`.
Do not include the terminal, Streamlit debug chrome, raw weights, PCA coordinates, or any caption that implies a recruited user study.

Save files here as PNG or WebP, each under 350 KB.

## Shots to take

| File | Screen | What to show |
|---|---|---|
| `01_discover.png` | Discover | Task cards, starting point, three priority chips, DEMO badge, synthetic disclaimer |
| `02_results_map.png` | Results | Schematic map with Top 3 numbered pins, Top 3 cards, synthetic disclaimer |
| `03_detail.png` | Space Detail | Why this space? (2 reasons + 1 trade-off), study-profile bars, Demo pulse empty or session-only state |
| `04_compare.png` | Compare | 2–3 spaces, decision hint, attribute table |

## Desktop

1. Browser width ≥ 1120 px.
2. Use the default Coding path: **Coding** · **North Gate** · Quiet / Power / Wi-Fi.
3. For Compare, add the first two Top matches.

## Mobile (390 px)

Repeat Discover and Results at 390 px width so the 1-column layout and 300 px map height are visible.
Suggested extras: `01_discover_mobile.png`, `02_results_mobile.png`.

## Captions that stay honest

Use: `Synthetic campus data · Schematic map · For prototype evaluation only.`

Do not use: “students reported”, “field study”, or “n = 12 participants”.
